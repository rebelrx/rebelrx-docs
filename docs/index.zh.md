# RebelRx Docs

欢迎来到 RebelRx Docs——一个提供实用指南的站点，帮助你构建自主的系统、保护隐私、掌控自己的健康。

---

## ⚠️ 核心原则

> 如果你不掌控自己的工具、数据和摄入的东西，就会有别人替你掌控。

RebelRx Docs 的存在，就是为了帮你把这份掌控夺回来。

---

## 🧭 本站内容

RebelRx Docs 提供一套精心整理的内容：

- **Linux 指南** → 干净、可控的替代操作系统，覆盖桌面与服务器
- **家庭实验室（Homelab）** → 由你自己拥有和维护的自托管基础设施
- **隐私** → 减少对监控型平台的依赖  
- **健康** → 尊重证据、聚焦根本原因的健康教育
