# RebelRx Docs

Добро пожаловать в RebelRx Docs — источник практических руководств по построению суверенных систем, защите приватности и контролю над собственным здоровьем.

---

## ⚠️ Основной принцип

> Если вы не контролируете свои инструменты, свои данные и то, что в вас поступает, — их контролирует кто-то другой.

RebelRx Docs существует, чтобы помочь вам вернуть этот контроль.

---

## 🧭 О чём этот сайт

RebelRx Docs предлагает тщательно отобранную коллекцию:

- **Руководства по Linux** → Чистые, контролируемые альтернативные операционные системы для десктопа и сервера
- **Homelab** → Самостоятельно размещаемая инфраструктура, которой владеете и которую обслуживаете вы
- **Приватность** → Снижение зависимости от платформ, построенных на слежке  
- **Здоровье** → Образование с опорой на доказательства и поиском первопричин
